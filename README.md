# Orbit · Орбита

**Расписание колледжей и вузов в одном месте.** Для студентов и преподавателей: своя группа или свои пары сразу при входе, текущая пара, свободные кабинеты, работа без интернета.

> **Статус:** ранняя разработка. Приложения пока нет, но данные уже есть: расписание СИЭУиП и СПК обновляется каждый час и публикуется в открытом виде.

## Что уже работает

- **[Стандарт данных](standard/)** версии 0.2: схема, примеры и проверка документов.
- **Коннекторы СИЭУиП и СПК**: раз в час забирают текущую и следующую недели и сохраняют [историю изменений](https://github.com/NikkiShuRA/orbit-schedule/commits/data).
- **Открытые данные** на [GitHub Pages](https://nikkishura.github.io/orbit-schedule/data/index.json): неделя целиком, неделя каждой группы и каждого преподавателя, оглавление для поиска.

Что делается сейчас и что дальше — на [доске проекта](https://github.com/users/NikkiShuRA/projects/9); что уже сделано — в [журнале изменений](CHANGELOG.md).

## Идея

У каждого учебного заведения свой формат расписания: JSON из 1С, таблицы xlsx, сканы PDF. Orbit приводит их к одному открытому стандарту и показывает в одном удобном интерфейсе.

- **Коннекторы.** У каждого источника свой коннектор, который читает исходные данные и приводит их к стандарту.
- **Открытый стандарт.** Схема данных расписания описана отдельно от приложения, ею может пользоваться кто угодно.
- **Честность данных.** Orbit показывает то, что опубликовало учебное заведение, ничего не додумывает и прямо пишет, если данные сохранены на устройстве и могли устареть.

Orbit — независимый некоммерческий проект и не связан ни с одним учебным заведением.
