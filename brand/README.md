# Логотип Orbit · Орбита

Знак — разомкнутая орбита со спутником. Это одновременно первая буква названия в обоих алфавитах (О в «Орбите», O в «Orbit») и метафора продукта: орбита — учебная неделя, коралловый спутник — сам пользователь, который движется между корпусами и кабинетами.

Основной логотип — название, в котором знак заменяет первую букву: «◉рбита» / «◉rbit». Надпись набрана Wix Madefor Display Bold и переведена в контуры, шрифт ставить не нужно.

## Файлы

| Файл                                          | Для чего                                                         |
| --------------------------------------------- | ---------------------------------------------------------------- |
| `orbit-logo-ru.svg`, `orbit-logo.svg`         | Основной логотип для светлого фона                               |
| `orbit-logo-ru-dark.svg`, `orbit-logo-dark.svg` | То же для тёмного фона                                         |
| `orbit-mark.svg`, `orbit-mark-dark.svg`       | Знак без подложки для светлого и тёмного фона                    |
| `orbit-mark-mono.svg`                         | Знак в одном цвете (`currentColor`): интерфейс, печать, гравировка |
| `orbit-icon.svg`                              | Знак на плашке: иконка приложения, аватар                        |
| `orbit-icon-square.svg`                       | То же с квадратной плашкой: maskable-иконка Android и iOS        |

Иконки приложения в `app/public/` получены из этих файлов:

| Файл приложения | Из чего |
| --- | --- |
| `icon.svg` (favicon), `icon-192.png`, `icon-512.png` | `orbit-icon.svg` |
| `icon-maskable-512.png` (Android), `apple-touch-icon.png` (iOS, 180 px) | `orbit-icon-square.svg` — та же иконка с квадратной плашкой |

Знак целиком лежит в безопасной зоне maskable-иконки (круг в 80 % размера), поэтому отдельная версия с уменьшенным знаком не нужна. PNG отрисованы из SVG без изменений (resvg); после правки SVG их нужно отрисовать заново.

Логотип в приложении — `orbit-logo-ru.svg` и `orbit-logo-ru-dark.svg` (`app/src/assets/`).

## Плашка — только для иконок

Сам логотип плашки не имеет. Закруглённый квадрат появляется только там, где знаку нужен свой фон: иконка приложения, favicon, аватар в соцсетях. Для iOS и maskable-иконки Android плашка отдаётся квадратной без скругления — форму задаёт сама система.

## Цвета

| Цвет         | Значение  | Где                                    |
| ------------ | --------- | -------------------------------------- |
| Ночь         | `#1f2238` | Знак и надпись на светлом, плашка      |
| Коралл       | `#ff7a59` | Спутник, акцент                        |
| Белый        | `#ffffff` | Орбита на плашке и на тёмном фоне      |
| Светлый текст | `#f3f3f0` | Надпись на тёмном фоне                |

Жёлтый `#ffe16c` — фирменный цвет СИЭУиП, поэтому в бренде Орбиты он не используется.

## Цвета в интерфейсе

Коралл на белом даёт контраст 2,57:1 — меньше нормы WCAG и для текста (4,5:1), и для элементов управления (3:1). Поэтому на светлом фоне коралл — только декор (спутник), а текст и ссылки — цветом «Ночь» (15,6:1). На тёмном фоне коралл даёт 6,8:1 и годится для ссылок и акцентов.

## Правила

- Минимальный размер знака — 16 px.
- Вокруг логотипа — свободное поле не меньше половины высоты знака.
- Спутник всегда коралловый, кроме одноцветной версии.
- Знак не поворачивать: разрыв орбиты и спутник всегда справа сверху.
