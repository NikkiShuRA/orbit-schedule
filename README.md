# Данные Orbit

Эта ветка хранит расписание, которое коннекторы [Orbit](https://github.com/NikkiShuRA/orbit-schedule) забрали у учебных заведений и перевели в [стандарт Orbit](https://github.com/NikkiShuRA/orbit-schedule/tree/main/standard).

Ветку ведёт задача GitHub Actions [`publish.yml`](https://github.com/NikkiShuRA/orbit-schedule/blob/main/.github/workflows/publish.yml). Руками её не правят. Коммит появляется, только когда расписание действительно изменилось, поэтому история ветки — это история изменений расписания.

## Устройство

```
<источник>/<понедельник недели>.json   документ стандарта за неделю
```

Например, `sieup/2026-11-09.json` — неделя СИЭУиП с 9 ноября 2026.

Данные — ровно то, что опубликовало учебное заведение, без догадок и исправлений. Откуда и когда получен документ, указано в его поле `provenance`. Когда источник проверяли в последний раз, показывает файл `<источник>/status.json` на опубликованном сайте. В ветку он не попадает, иначе каждая проверка была бы коммитом.

Orbit не связан ни с одним учебным заведением.
