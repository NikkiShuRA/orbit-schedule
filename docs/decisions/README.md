# Проектные решения (ADR)

Здесь фиксируются принятые решения, чтобы их не приходилось обсуждать заново.

Файл называется `NNNN-короткое-название.md` (номер по порядку) и содержит:

- **Статус** — предложено / принято / заменено решением NNNN.
- **Контекст** — какая проблема и какие были варианты.
- **Решение** — что выбрали.
- **Последствия** — что это меняет и чем мы за это платим.

Пример: `0001-format-standarta-raspisaniya.md`.
